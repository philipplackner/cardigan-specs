Direction A

Graphite

Quiet precision. Cool neutral greys, hairline borders and one cobalt accent saved for actions and focus. It reads like a well-made developer tool: dense, calm and fast to scan, with keyboard hints visible everywhere.

Strengths

  • Highest information density
  • Ages well; nothing to get tired of
  • Easy to build on both stacks

Watch out

  • Close to Linear and Height in feel
  • Personality relies on small details
Type
Geist for UI and headings, Geist Mono for card IDs, counts and shortcuts
Color
Blue-tinted greys, cobalt accent, labels as small colored dots
Shape
8px cards, 6px controls, 1px hairlines, barely-there shadows
Density
Compact: 13–14px UI text, 32px controls
Mobile
Same tokens; columns become segmented tabs, one column per page

Direction B

Ledger

A technical printout. Black ink on white, square corners, heavy rules between columns and monospace for everything structural. Highlighter yellow marks what's active: the selected board, the dragged card, the primary button. Opinionated and impossible to mistake for anything else.

Strengths

  • Most distinctive and memorable
  • Very high contrast, very legible
  • Cheap to render: no shadows or blur

Watch out

  • Polarizing; some people find it harsh
  • Monospace headers take more width on phones
Type
IBM Plex Mono for headings, columns, IDs and buttons; IBM Plex Sans for card text
Color
Pure black and white, highlighter yellow as the single accent, labels as colored squares in a box
Shape
0px radius, 1.5px solid rules, hard offset shadows for lifted states
Density
Medium; ruled grid gives structure instead of whitespace
Mobile
Column tabs become a ruled strip; active tab is highlighted yellow

Direction C

Chroma

Soft and tactile. Columns sit in rounded trays, cards float with gentle depth, and labels are colorful filled pills that make a board readable at a glance. A bold grotesque for titles and a punchy pink accent give it energy without losing the tool feel.

Strengths

  • Labels carry the most meaning visually
  • Feels at home on touch devices
  • Friendliest first impression

Watch out

  • Less dense; fewer cards per screen
  • Colorful boards get busy with many labels
Type
Bricolage Grotesque for board and card titles, Onest for UI text, Geist Mono for IDs
Color
Lilac-grey ground, pink accent, pastel label pills (deep tints in dark mode)
Shape
14px cards, 18px column trays, pill buttons, soft layered shadows
Density
Relaxed: 14px card text, generous padding
Mobile
Pill tabs for columns, floating add button

What I need from you

  1. Pick one direction, or name the parts you want to mix (for example "Graphite's density with Chroma's labels").
  2. Tell me what to change about it: accent color, typeface, corner radius, density.
  3. I'll then build the full design system and every screen at phone, tablet and desktop sizes in light and dark.

All typefaces are open-source (OFL) and can be bundled into the Compose Multiplatform app as well as served on web.
