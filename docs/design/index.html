Cardigan screens

Static mockups of every Cardigan v1 screen in the Graphite style, one page per flow. Web and the app share these designs at phone (390), tablet portrait (834) and desktop (1440) width; tablet landscape uses the desktop layout. Below the page list: the decisions the screens are based on.

Pages

Foundations

Graphite tokens and components shared by web (React) and the app (Compose Multiplatform). Colors switch with the system theme.

Log in & register

Log in and register are the only signed-out screens. There is no password reset or email verification in v1.

Board list

Home screen after login. Grid of tiles on tablet and desktop, list on phones. Tiles show name, key, card count and last update. Export is only in the board view menu.

Board view

Columns side by side with horizontal scroll. On phones the next column peeks in from the right. Column actions are all in the column’s … menu; cards are added inline at the bottom of a column.

Card detail

Opens as a side panel on tablet and desktop, full screen on phones. The description is plain text. Changes are saved with the Save button. To move a card, drag it on the board.

Labels

One label set for all boards, managed on its own page. Each label has a name and one of 20 colors.

Import & export

Each is one blocking request with a progress dialog. Export starts from the board’s … menu. Import starts from the board list; on the app it opens the system file picker.

Look

  • Graphite: cool greys, cobalt accent, hairlines
  • Geist for UI, Geist Mono for IDs and metadata
  • Follows the system theme; no theme setting in the app
  • One shared look on web, Android and iOS

Cards

  • Title, plain-text description (no Markdown), labels
  • Created and updated time, read-only
  • ID = board key + number, e.g. CRD-109
  • Quick add (title only) at the bottom of a column
  • Side panel on wide screens, full screen on phones
  • Explicit Save; unsaved changes are confirmed
  • Moved between columns by drag & drop only

Boards & columns

  • Name + key (2–5 uppercase letters, unique, fixed after creation)
  • New boards get To do / In progress / Done
  • Grid of tiles (list on phones): name, key, card count, last update
  • Phone board scrolls sideways
  • Column actions in a … menu
  • Deleting a column deletes its cards after a confirm

Labels, search & filter

  • Labels are per user, shared by all boards
  • 20-color fixed palette
  • Own Labels page; no inline creation in the picker
  • Search matches title, description and card ID
  • Several labels match any (OR)

Account

  • Register: email, password, repeat password
  • Password: 12+ characters with a lowercase letter, an uppercase letter and a digit, checked live (cross → check) while typing
  • No settings screen; Log out in the sidebar (wide) or menu (phone)
  • Session expiry returns to Log in with a message

Import & export

  • Export from the board view … menu
  • Web import: dialog with drop zone; app: system file picker
  • Files up to 5 MB
  • Key already used → ask for a new key
  • After import: stay on the board list; a toast confirms

Navigation & sizes

  • Web and app share one set of designs: phone, tablet portrait, desktop
  • Tablet landscape uses the desktop layout
  • Tablet and desktop: persistent sidebar; phone: board list + menu
  • App refreshes by pulling down; web has a refresh button
  • All deletions use a confirmation dialog

Proposals to confirm (not from the plan)

  • Breakpoints: web phone below 640px, tablet 640–1023px, desktop from 1024px; app tablet layout from 600dp width.
  • Search and label filter live in the board header (wide) or open from the top bar (phone).
  • Search and label filter combine: a card must match the text and have one of the selected labels.
  • Quick add keeps the field open after Enter so several cards can be added in a row.
  • Time format: relative for recent updates (“2 hours ago”), dates after a week.
